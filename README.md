# MastoFrame

**Turn Mastodon posts into beautiful, shareable images.**

# [VISIT MASTOFRAME →](https://mastoframe.pages.dev)

MastoFrame is a simple, free web tool that transforms public Mastodon posts into visually appealing square images, ready to download and share.

## Features

- Paste a public Mastodon post URL.
- Dark and Light modes.
- Custom background colors.
- Optional engagement statistics.
- Square image generation.
- Download generated images as PNG.
- Simple and responsive interface.

## How to Use

1. Copy a public Mastodon post URL.
2. Paste it into MastoFrame.
3. Click **Create**.
4. Customize the appearance.
5. Download your image.

## Built With

- HTML
- CSS
- JavaScript
- Mastodon API
- Cloudflare Pages

## Why MastoFrame?

Social media posts are often shared through screenshots, but those screenshots can be messy and inconsistent.

MastoFrame makes it easier to turn Mastodon conversations into clean, attractive visuals that can be shared beyond the Fediverse.
